# @embroidery/design-document

Framework-independent design-document types, validation, serialization and migrations.

## Status

Approved package boundary with no implementation yet (created in CP0).
`src/index.ts` is intentionally empty — no placeholder business logic.

## Boundary

Must stay framework-independent: no React, no NestJS, no canvas library. The canvas library is an open decision and must not be introduced here.
