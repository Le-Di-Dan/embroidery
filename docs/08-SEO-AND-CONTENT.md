# 08 — SEO and Content

**Status:** Approved product baseline  
**Version:** 0.1.0

## 1. SEO priority

SEO is a core acquisition channel because the website is intended to become the primary online sales channel.

## 2. Content model

Required SEO-capable page types:

- Home.
- Service page.
- Category page.
- Product page.
- Gallery entry.
- FAQ.
- Local/store page.
- Demand-focused landing page.
- Policy pages.

A blog publishing system is not required.

## 3. Example landing topics

- Thêu tên lên khăn.
- Thêu chữ lên gấu bông.
- Thêu hình lên áo.
- Thêu quà tặng cá nhân hóa.
- Thêu logo số lượng ít.
- Thêu áo đồng phục.
- Thêu theo yêu cầu tại địa phương.

## 4. On-page requirements

Each indexable page should support:

- SEO title.
- Meta description.
- Canonical URL.
- Social preview image.
- Structured heading hierarchy.
- Alt text.
- Internal links.
- Breadcrumb.
- Structured data where appropriate.
- Index/noindex control.

## 5. Technical SEO requirements

- Server-rendered or pre-rendered indexable content.
- Sitemap.
- Robots control.
- Canonicalization.
- Clean URLs.
- Redirect management.
- Image optimization.
- Core Web Vitals.
- Mobile-first design.
- Avoid rendering critical SEO text only inside client-side canvas.
- Product and gallery metadata must exist outside image assets.

## 6. Gallery SEO

Gallery entries should include text context, not image-only pages.

Recommended fields:

- Title.
- Product type.
- Embroidery style.
- Short description.
- Related product.
- Related service.
- Alt text.
- Location context where legitimate.
- Publication status.

## 7. Content quality

Do not create mass-generated low-value landing pages.

Each page must provide:

- Clear service intent.
- Real examples.
- Useful customer information.
- Accurate limitations.
- Relevant internal links.
- Strong call to action.

## 8. Analytics readiness

The product should be ready to measure:

- Organic landing page visits.
- Product view.
- Start customizer.
- Submit request.
- Zalo click.
- Messenger click.
- Quotation view.
- Approval.
- Deposit.
- Completed order.

Tool selection is deferred.
